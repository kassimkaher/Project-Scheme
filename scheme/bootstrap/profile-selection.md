# Profile selection

Choose `small` for short-lived, low-complexity work with few maintainers. It uses simple feature-first organization and lightweight gates.

Choose `production` for a maintained product with real users and feature growth. It uses feature-first organization, contracts, environments, integration QA, and release discipline.

Choose `enterprise` for multi-team, sensitive, highly integrated, or long-lived systems. It adds modular boundaries, stronger security and release gates, and explicit operational concerns.

Platform and risk answers always refine the profile. A small web project must not receive mobile guidance; a regulated production project may need security guidance even if it is not enterprise.

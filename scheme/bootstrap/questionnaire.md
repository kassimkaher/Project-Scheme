# Bootstrap questionnaire

Ask compactly and group related decisions. Required: project name, product description, project type, expected lifetime, team shape, expected growth, enabled platforms, database, environments, QA targets, and security sensitivity.

Ask only when relevant: authentication, multi-tenancy, payments, files/media, notifications, realtime, offline behavior, mobile flavors or native schemes, deployment targets, regulated data, design source, and API contract source.

Record answers in YAML using `project.schema.json`. Never place credentials in the answer file or generated project files.
